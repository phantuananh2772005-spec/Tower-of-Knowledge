# Unified learning garden scenery

Nine full illustrated environments (everyday plus eight holiday themes), each with spring, summer, autumn and winter variants. The existing chapter-index modulo-four season cycle remains. Theme follows the same selector as page scenery and navigation icons. Vietnamese winter uses cool mist/foliage rather than snow. No animals or cultural monuments were added.

Built-in image generation prompt set: 2x2 atlas of four seasons; elevated three-quarter view of a modern Vietnamese study garden, matching existing cream/sage watercolor scenery and navy/gold illustrated app icons. Clear central 50% for interactive nodes and SVG paths; foliage, flowers and modest books/benches at the sides; common pale sage-ivory ground at panel boundaries. No UI, text, drawn routes, people, animals, pagodas, bronze drums, flags/emblems, traditional headgear or fantasy castles. Holiday details: pumpkin/lantern; Teachers Day bouquet/pen; Christmas evergreen/baubles/light without snow; New Year gold stars/light; Tet apricot/peach blossoms and plain red envelopes; Valentine roses/envelope; 8 March tulips; 26 March seedlings/daisies/blue flowers.

Boss icons are separately generated paper crowns seen from above in three-quarter perspective, with visible folded ivory/navy paper, small sticky notes and minimal holiday stickers. Learning icons reuse the approved themed ordinary-book illustrations. Current pet replaces the icon, centered on the round pedestal. Brand and pet sprites remain unchanged.

`tools/export_garden_v2.py` crops the four panels, resizes without upscaling and exports AVIF/WebP in 480 and 960 request slots. Desktop slot originals are 539x720; mobile 480x641. AVIF files are approximately 20–34 KiB per scene. PC uses proportional cover; mobile repeats proportional tiles whose top/bottom edges fade through CSS gradients. Artwork never stretches with the number of milestones. Neighboring chapter scenes crossfade over an overlap; their SVG routes remain independent.

Initial and active chapter scenery loads immediately; other chapters load near the scroll viewport. Only the current theme is used. Theme and viewport changes refresh loaded scenes; returning to the map refreshes its art without fetching hidden map backgrounds while on another page. CSS keeps touch/click targets and node coordinates separate from decoration.

Validation: `node tests/test_garden_scenery.js` uses an isolated local UI fixture (no database mutation), five chapters/25 milestones, nine themes, light/dark, 390/768/1440 widths, real visible map assertions, reached finish, independent paths, chapter season loop, checkpoint/locked click behavior, centered pet, reduced motion and asset responses. Captures top and chapter-seam screenshots. The PostgreSQL-backed `tests/test_learning_garden.js` asset expectation was updated; database checks are not required for these visual changes.
