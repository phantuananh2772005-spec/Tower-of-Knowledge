# Seasonal light/dark switch art

WebP derivatives of generated artwork. Original holiday atlas: exec-a72d72ff-154b-496d-8605-2c4da287b09d.png. Original sky/Halloween: exec-03bed8fa-054c-4efd-9001-033724b6f8fc.png. Cropped and resized, original PNGs retained in the task outputs.

Selection: automatic by Asia/Ho_Chi_Minh date or manual device preference in Settings. Only the selected theme assets are requested. Seasonal windows: Halloween Oct25–Nov2, Teachers Nov15–21, Christmas Dec15–26, New Year Dec27–Jan3, Tet Jan30–Feb12 2027 only, Valentine Feb13–15, Women's Day Mar5–9, Youth spring Mar23–27. Tet is year-specific; future years require confirmed lunar dates. Outside windows: sky.

Desktop uses a sliding thumb; mobile uses a single stationary icon. Reduced motion disables thumb motion and twinkling.
