Reference image is the website's dragon-and-book LOGO: use its crisp angular illustrated shapes, deep navy and azure blue edges, warm ivory highlights and small flame-orange accents. Do NOT draw the logo or four dragons. Create symbols in the SAME hand-illustrated cel-shaded fantasy emblem language. Top-right: two bold arrow ribbons forming an open circular loop, navy shaded undersides, azure highlighted faces, small ivory diamond at center. Bottom-left: a navy and ivory compass with an orange needle, tilted slightly to show a thin rim and depth, simple navigational application symbol. Bottom-right: sharp elegant golden-orange three-point crown, navy inset shadow planes and a single cyan diamond gem. Each icon occupies its own equal square quadrant with generous clear separation. Readable at 56px. Create DEPTH THROUGH PERSPECTIVE, OFFSET EDGE PLANES AND CEL SHADING, like polished illustrated game UI symbols. This is a 2D drawing with dimensional illusion, NOT a 3D render. NO clay, NO felt, NO toy style, NO blobby rounded material, NO rough texture, NO photographic lighting, NO glow, NO ground or base, NO cast-shadow backdrop, NO letters. Sharp silhouette, controlled highlights and limited harmonious palette. Genuine transparent alpha outside the four symbols.
